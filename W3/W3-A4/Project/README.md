**I added a separate Course table**
 To make the database structure clearer and more organised I added a separate course table. In the original ER diagram, the course name was included in the Enrollment table, which could cause the same course information to be repeated. The separate Course table allows each course to have its own record and makes it easier to count and manage the students enrolled in each course.
